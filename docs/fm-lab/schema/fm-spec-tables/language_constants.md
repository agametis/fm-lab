# language_constants

Part of the [FM-Lab schema](../Schema.md) · Language layer · `reference/fm_spec.duckdb` (fm-spec language reference)

Canonical spellings of language-level constant tokens (text style constants such as `Bold` or `HighlightYellow`, and similar literals) so parsed and generated calculations use one canonical form.
