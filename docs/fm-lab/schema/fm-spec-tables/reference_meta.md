# reference_meta

Part of the [FM-Lab schema](../Schema.md) · Metadata · `reference/fm_spec.duckdb` (fm-spec language reference)

The build stamp of the shipped reference as key/value pairs: schema version, FileMaker coverage (currently 22), build timestamp, source commit, build variant and the pointer to the attribution file (`SOURCES.md`).
